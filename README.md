# IMP Labs

Repositório do [implabs.com.br](https://implabs.com.br) — meu espaço próprio na internet, onde construo minha marca como desenvolvedor.

## Sobre

O IMP Labs é o meu portfólio.

Por trás dele estou construindo um sistema, à mão, como exercício de engenharia — API, banco de dados, migrations e testes. O front é a vitrine; o back é o treino.

## Stack

- React 19 + Next.js 16 (Pages Router)
- Next.js API Routes
- PostgreSQL 18 em Docker Compose
- node-pg-migrate para migrations versionadas
- Jest para testes
- Prettier para formatação

## Como rodar

Requisitos: Node.js, Docker e Docker Compose.

```bash
git clone https://github.com/Ismaelthe10/implabs.git
cd implabs
npm install
npm run dev
```

O `npm run dev` sobe o PostgreSQL antes de iniciar o Next.js. A aplicação roda em `http://localhost:3000`.
